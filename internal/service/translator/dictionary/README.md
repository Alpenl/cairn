# Traditional-to-Simplified dictionaries

`TSPhrases.txt` and `TSCharacters.txt` are the dictionaries selected by the
OpenCC `t2s` configuration. They were obtained from
`github.com/longbridgeapp/opencc` v0.3.13, which synchronizes the official
OpenCC dictionaries.

The dictionary files are redistributed under the Apache License 2.0. The full
license text is retained in `LICENSE` in this directory. WebTag's matcher is an
independent implementation and does not include the former GPLv2 matcher
dependency.
